# date-fruit-classification
Ensemble deep learning model for Date Fruit variety classification using YOLOv9,DETR,EfficientDet

## Overview
An ensemble deep learning framework to classify 9 varieties 
of date fruits using YOLOv9, DETR, and EfficientDet D3/D4.

## Technologies Used
- Python
- PyTorch
- YOLOv9
- DETR (Detection Transformer)
- EfficientDet D3/D4

## Results
- Achieved over 90% classification accuracy on validation dataset

## Models Used
- YOLOv9 – Real-time object detection
- DETR – Transformer-based global attention
- EfficientDet – Compound scaling for robust classification
